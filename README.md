## About Me

I am a developer focused on building practical tools, automation scripts, clean Windows utilities, and useful project setups.

I work with PowerShell, GitHub, Docker, Linux servers, Windows tools, and web-based workflows.  
My focus is not only making things work, but making them look clean, feel professional, and be easy for other people to use.

I am currently building and improving projects under **LC-Devs**, with a focus on automation, cleanup tools, developer utilities, and simple tools that people can run directly from PowerShell.
